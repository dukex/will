# introduction

Will is an Android launcher that treats your phone as a work surface, not an attention sink.

## what it does

- captures notifications and turns them into a task list
- provides a minimal app grid (swipe up from the home screen)
- includes an overlay for active task management
- no streaks, no badges, no engagement mechanics

## status

Will is under active development. basic launcher and notification capture are complete.
manual task creation, task lifecycle tracking, focus dashboard, and privacy settings are in progress.
