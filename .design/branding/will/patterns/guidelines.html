Pairing note

Geist Sans handles content the user reads (task titles, action labels, section headers). Geist Mono handles values the system generates (timestamps, source app names, task IDs). The typeface communicates the category before the user reads the content — the same function as syntax highlighting.

Weight policy400 Regular for all content. 500 Medium for section headers only. Never 600+ (SemiBold/Bold).
Scale ratioMajor Second (1.125) — compact, appropriate for information-dense launcher UI
Android bundlingBundle in res/font/ — no Downloadable Fonts API (privacy, offline)
Fallback — SansGeist Sans → Inter → Roboto
Fallback — MonoGeist Mono → JetBrains Mono → Roboto Mono → monospace

Persona
Lucas
Developer / Product Designer · 25–35
Day in the life
Starts the day with a backlog of Slack messages and GitHub notifications. Uses the phone as a work tool but keeps getting pulled into social media or infinite scroll. Has tried Notion, Todoist, and several launchers — each requires too much maintenance or adds cognitive overhead.
Frustration
Every "minimal" launcher is either all aesthetics with no function, or productivity apps that feel like more work on top of work. He doesn't want to be managed — he wants the phone to stop wasting his time.
Aspiration
Pick up the phone, do the thing, put it down. The phone should match his mental model: there's a task, complete it, move on.
Trust signals
Open source, clear opinions, no dark patterns. Distrusts engagement metrics, growth hacks, UI that celebrates streaks.
Voice & Tone
Precise
Every word carries specific weight. Nothing is approximate, hedged, or padded. Will writes the way well-typed code reads.
Dry
No emotional inflation. No enthusiasm signals. Will does not perform positivity at the user. It states things.
Uncompromising
Will has positions and states them. When the architecture makes a choice, the copy says so without apologizing.
Peer-to-peer
Will speaks to Lucas as a fellow builder. Assumes the reader already understands the problem. Does not explain the attention economy to someone who has read the papers.

Style rules
× Exclamation marks — ever
× Emoji in product, docs, or release notes
× "we" as subject — Will is the subject ("Will converts…" not "We convert…")
× Wellness language — "calm," "balance," "mindful," "streak"
→ Sentence case everywhere ("Task feed" not "Task Feed")
→ "task" not "to-do" — a task is a unit of intent
→ "captured" not "received" — notifications are captured from the attention economy
→ "tap to execute" not "open" — execution is intentional
