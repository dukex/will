# Logo Directions
> Phase: identity | Brand: will | Generated: 2026-04-15

---

Three directions. Each is a full proposal with construction geometry, variation specs, and usage rules.

---

## Direction 1 — Wordmark: Will as tool name

### Concept
The brand is the name. "will" set in Geist Sans lowercase, tracked tight, treated as a command-line tool name — `will`, not Will, not WILL. The same visual register as `git`, `curl`, `brew`. It signals: this is a tool, not an app.

### Strategic rationale
The Sage archetype demands clarity over expressiveness. A pure wordmark with no decorative mark says: the name carries enough meaning. It does not need an icon to explain itself. This is how serious developer tools present — Vercel, Linear, Supabase all lead with a wordmark that functions as a proper noun in the toolchain.

### Visual description
- Typeface: Geist Sans, weight 400 (regular)
- Case: all lowercase — mirrors terminal convention of tool names (`grep`, `awk`, `will`)
- Color: `#F0F0F0` on `#000000`
- Tracking: -2% (tight enough to read as a single token)

### Construction geometry
- Character grid: set on a 4dp baseline grid
- Letter spacing: -0.02em (approximately -0.28px at 14px)
- Cap height reference: ≈ 70% of type size in Geist Sans
- Optical margin: no additional margin on left — the `w` letterform aligns flush to the margin

### Variations

| Variant | Description |
|---------|-------------|
| **Primary** | `will` Geist Sans 400, `#F0F0F0`, lowercase, -0.02em tracking |
| **Icon (48dp)** | `w` letterform, Geist Sans 500, `#F0F0F0` on `#000000` square. 4px corner radius for Android adaptive icon grid only. |
| **Wordmark (type only)** | Identical to primary — this direction has no separate symbol |
| **Monochrome** | `#FFFFFF` on black (dark contexts) or `#000000` on white (press kit, OG card) |

### Clear space rules
- Minimum clear space: 0.5× the cap height on all four sides
- At 14px type: minimum 5px clear space all sides
- At 24px type: minimum 8px clear space all sides

### Minimum size
- Full wordmark: 14px (below this, use icon variant)
- Icon (`w`): 16px minimum; 48dp for Android launcher icon

### Don'ts
- No tagline attached as a visual lock-up — voice is delivered through copy
- No outlined, gradient, or colored variant — always two-tone
- No stretching or condensing the letterforms
- Do not set in uppercase or title case — the lowercase is the mark

## Direction 2 — Geometric mark + wordmark: The bracket

### Concept
A vertical bracket — `[` — as a standalone mark, paired with the wordmark "will" in Geist Mono. The bracket is a structural device in every programming language: it denotes scope, containment, and context. Will captures notification context and converts it to task scope. The bracket is the visual shorthand for that operation.

### Strategic rationale
The Creator 30% earns its weight here. A single bracket is semantically precise: it marks the boundary between raw input and structured scope. Not a checkmark (wellness), not a lightning bolt (productivity) — a bracket. The Geist Mono pairing reinforces the technical-tool register: the brand name looks like a variable name.

Differentiation: Niagara and Minimalist Phone use soft marks or no marks. A bracket is owned territory for Will.

### Visual description
- Mark: single left square bracket `[` from Geist Mono 500
- Mark color: `#4F6EF7` (the only context where the accent appears in the identity mark — the bracket IS the action metaphor)
- Wordmark: `will` in Geist Mono 400, `#F0F0F0`, lowercase
- Lock-up: `[will` — intentionally open bracket, no closing bracket, implies task in progress

### Construction geometry
- Bracket height: 1.2× cap-height of adjacent wordmark
- Gap between bracket and wordmark: 8dp
- Bracket weight: Geist Mono 500 at all sizes
- Baseline alignment: bracket and wordmark share the same baseline
- Lock-up bounding box: tight to character metrics, no additional padding built in

### Variations

| Variant | Description |
|---------|-------------|
| **Primary** | `[will` full lock-up as described |
| **Icon (48dp)** | `[` bracket alone, `#4F6EF7` on `#000000`, Geist Mono 600 for weight compensation at small sizes |
| **Compact** | `[w` — bracket + first letter only, for 24dp icon contexts |
| **Monochrome** | Bracket in `#F0F0F0` (no indigo) for single-color contexts |

### Clear space rules
- Minimum clear space: 1× bracket width on all sides
- The open bracket must not be cropped — clear space applies to the left side of `[`

### Minimum size
- Full lock-up `[will`: 16px type minimum
- Icon `[`: 24dp minimum for legibility; 48dp for Android launcher icon
- Below 16px full lock-up: use `[` icon variant only

### Don'ts
- Never use the closing bracket `]` — the open form is the mark
- Do not use `[will]` — the closed form changes the meaning
- Do not rotate the bracket
- Do not use the bracket as a frame around other elements
- No stacked lock-up (wordmark above mark)

## Direction 3 — Wordmark with structural weight shift

### Concept
"will" as wordmark where the double-L (`ll`) is set in a contrasting weight — `wi` in 400, `ll` in 500. The double-L in "will" is structurally unique: two identical vertical strokes side by side. A minimal weight shift makes them read as a structural column — a load-bearing element. The visual metaphor: the name has structure, it does not just sit on the page.

### Strategic rationale
Most Sage-dominant direction. No symbol, no metaphor, no geometric element — just type with a decision. The weight shift is a typographic argument: these two characters are the architectural signature of the word. For the developer persona, this reads as opinionated but not stylized. The Creator 30% shows in the craftsmanship: 400 → 500 (not 400 → 700, which would read as a logo stunt).

### Visual description
- Typeface: Geist Sans throughout — weight split only, no other variation
- `wi`: Geist Sans 400, `#F0F0F0`
- `ll`: Geist Sans 500, `#F0F0F0` (same color, weight shift only)
- No tracking modification — default spacing
- The double-L at 500 reads like a terminal cursor at rest

### Construction geometry
- Weight differential: exactly one step (400 → 500); the jump must be perceptible, not dramatic
- Character alignment: all four characters on the same baseline, no offset
- No artificial space between `wi` and `ll` — word flows normally
- Optical check: at 16px, the weight shift must be visible at normal reading distance

### Variations

| Variant | Description |
|---------|-------------|
| **Primary** | Full wordmark with weight split as described |
| **Icon (48dp)** | `ll` in Geist Sans 600, `#F0F0F0` on `#000000`. 4px corner radius for Android adaptive icon grid. |
| **Wordmark flat** | Single weight for monochrome contexts — Geist Sans 400 `#FFFFFF` |
| **Reversed** | `#000000` text on `#F0F0F0` background — for rare light-context use |

### Clear space rules
- Minimum clear space: 0.5× cap height on all sides
- Icon `ll`: 0.5× mark height on all sides minimum

### Minimum size
- Full wordmark: 16px (the weight differential becomes imperceptible below this)
- Icon `ll`: 20px minimum; 48dp for Android launcher icon
- Accessibility check: confirm `ll` icon is not confused with a pause/play symbol at actual icon sizes

### Don'ts
- Direction requires Geist Sans exclusively — the split is imperceptible in Geist Mono
- No color differentiation on the `ll` — weight shift only
- No three-weight version
- No italic treatment
- `ll` must not be used decoratively except in the icon slot
